# 📚 Boletim Escolar

Sistema web de boletim escolar desenvolvido para praticar HTML5, CSS3 e JavaScript.

O projeto permite visualizar informações do aluno, consultar notas, calcular médias, verificar situação acadêmica e consultar a frequência.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## 📋 Funcionalidades

- Visualização dos dados do aluno;
- Tabela com 8 disciplinas;
- Visualização das notas por bimestre;
- Cálculo automático da média;
- Verificação da situação do aluno;
- Consulta da frequência;
- Área de avisos;
- Formulário de consulta;
- Botão para imprimir o boletim;
- Botão para limpar o formulário;
- Navegação entre as seções;
- Layout responsivo;
- Efeitos de hover nos botões;
- Suporte para impressão.

## 📊 Regras de situação

A situação do aluno é definida de acordo com a média:

| Média | Situação |
|---|---|
| 7,0 ou maior | APROVADO |
| 5,0 até 6,9 | RECUPERAÇÃO |
| Menor que 5,0 | REPROVADO |
